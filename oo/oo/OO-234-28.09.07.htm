Office Order No. 234 dated 28 September 2007

 

Introduction of System of Registration

for User ID, Email ID and Internet Access

 

          As you are aware our Bank has successfully implemented the CBS (Centralized Banking System) project enabling it to offer various modern banking facilities to its valued customers.  We have recently introduced SMS banking facility and have further plans to offer various other I.T. based facilities in phased manner such as internet banking etc..  The CBS project facilitates connectivity among branches and departments through centralized datacentre.  The centralized environment provides lot of benefits in migrating and administering some business processes like CRC upload, posting etc.  The branches are provided centralized OMNI access on the basis of new user ID on centralized database.  The I.T. Dept. has been receiving a number of calls from branches/departments in various matters such as resetting of passwords, modification of user IDs, changing user status to operation mode etc.  All such calls are received on telephone at present.  However, henceforth the I.T. Dept. has introduced system of registration for user ID, Email ID and interest access by filling in following forms (copies enclosed) in order to streamline and systematize the process for creation of user ID and password maintenance and for access to OMNI and the Exchange Server: -    

 

1.  Email ID Request Form

2.  User ID and Password Maintenance Request Form

3.  Internet Access Registration Form

         

          A brief information is given below regarding the contents and the procedure to be followed by branches/departments while filing in the forms: -

 

1.     Email ID Request Form -

          The I.T. Dept. has already provided Exchange Server access to all      the staff members with designation equal to Asst. Accountant and above.  The newly promoted staff members have been requesting the I.T. Dept. to provide access to Exchange ID over telephone.  Henceforth the new Exchange ID creation process will require filling up the ‘Email ID Request Form’ and submitting the same to I.T. Dept. with approval from the branch/department authority.  The I.T. Dept. will thereafter create email ID on Exchange Server.  The ‘Email ID Request Form’ has been divided into two parts.  A) User Information details, User Signature and approval from Branch/Department Authority and B) Approval of DGM, I.T. Dept.

 

2.    User ID and Password Maintenance Request Form -

          This form will be used for requesting user ID and password      maintenance for OMNI applications as well as for Exchange Server.  This form is divided into following four parts: -

  A)    Particulars of Applicant: - In this section the applicant will complete all details like name, staff number, name of branch/department (he or she belongs to), and signature.  Also it will be mentioned as to which application (OMNI or Exchange Server) the request is related to along with the present ID.

  B)    Type of Request (User Selection): - In this section user will select the type of request he or she wishes to propose or to cancel.  The       request type is divided into two parts namely (I) ‘Application (OMNI) Request’ and (II) ‘Exchange Server Request’.

 

(I)      The ‘Application - OMNI Request’ has following nine points available for selection for the specific user IDs.

      i) Create New OMNI ID -

          Whenever new staff joins the Bank and requires to be given OMNI application access then that staff has to tick for this point, with due approval from the Branch/Dept. authority.

     ii)  Modify suspended ID to Operative -

          OMNI user ID gets suspended automatically within 7 days for branch and within 90 days for department.  In such cases if the next Login change date falls on holiday, User ID gets suspended.  The branch/department staff has to click on this option to make ID operative only in such cases.

    iii)  Modify branch code -

          All OMNI user IDs have been associated with branch or department codes.  The branch/department staff member is given new branch or department code upon his/her transfer.  In such scenario user has to click on this option to get his/her User ID (branch code) modified according to transfer order, only after reporting to the branch/department of transfer.

    iv)  Suspend OMNI ID -

          This option will be used when any staff is proceeding on privilege leave.  Such staff will request the I.T. Dept. to suspend his ID for the duration of his/her leave to prevent unauthorized access.

     v) Enable ‘Login From Other Branch’ -

          During the failure of branch connectivity to DC the branch staff has to operate from a nearby branch for rest of the day.  In such scenario the staff is required to have access from other branch code.  He/she has to click on this option to enable ‘Login from other branch’.

 

    vi)  Disable ‘Login From Other Branch’ -

          This option is used to disable ‘Login from other branch’ which was enabled vide option no. 5 above.

   vii)  Enable ‘Multi Branch Access’ -

          This option is used to enable OMNI access to view other branch information by sitting physically at his/her base branch.  The auditors, for instance, would ask for such type of access to operate from single branch.

  viii)  Disable ‘Multi Branch Access’ -

          This option is used to disable ‘Multi branch access’ which was enabled vide option no. 7.

    ix)  Change User group -

          OMNI User ID is created as per functionality/designation and the same needs to be upgraded or temporarily modified as per promotion list or in case of officiating duty allocated to lower level staff at branch.  The concerned staff member will click on this option to change his/her user group.

 

(II)    The Exchange Server request has five points as under for selection with the Email ID Request: -

 

     i)  Create Public Folder -

          Department/Branch will be able to request for creation of Public folder through this option available on the Form.

    ii)   Reset Password -

          Many a times it is observed that Email ID password needs to be reset due to non-use for a long time OR any other reasons.  In such cases the concerned staff member will be able to request to reset Email ID password to Default value with this option.

    iii)  Delete ID -

          Branch Manager will be able to request to delete Email ID for the staff that is leaving the organization OR completing the officiating term for the said post.

    iv)  Enable ID -

          This option will be used to enable Email ID which gets disabled due to various unknown reasons.

     v) Others -

          This option will be used for specific request related to Email ID modifications like change in name, increase in space limit etc.

 

          All the above requests marked in the Request Form need to be justified by giving proper reasons which should be mentioned against the field ‘Reason For The Request’.  Every request for OMNI User ID OR Email ID should be justified with a reason for the purpose of approval.

 

  C)    Request Approval: -

          This section will provide for approval status of the request.  There will be two types of approvals namely ‘Department Head/Branch Manager Approval’ and ‘I.T. Dept. Approval’.  The concerned staff member will take approval of the respective branch manager or department head at the branch/department level.  The branch manager/department head will enter request number in ‘Please approve Request No.’ field as per the register maintained at the branch/department.  After approval of the branch manager or department head the request will be forwarded to the I.T. Dept., where the concerned I.T. Dept. officer will take approval of the DGM, I.T. Dept. and process the request.

  D)    For IS Admin Use Only: -

          The I.T. Dept. will forward fully approved request form to the IS admin section.  The Information Security staff will implement the requested changes with User ID and record Maker/Checker details in the form.

 

3.     Internet Access Registration Form: -

          This form will be used to request ‘Internet Access’ at branch or department nodes.  The form is divided into three parts containing details of applicant and his/her IP address and particulars purpose of internet access and the approval of the I.T. Dept..  The details and approval process will be same as explained in above forms (mentioned in above items 1 & 2).  The user has to provide his/her IP address of machine which will be added in firewall placed at Central Datacentre.

 

          As regard the above system of registration a reference is invited to our previous Office Order No. 229 dated 21st June, 2007 on the misuse of internet connection.  The cautions given therein are also applicable to the misuse of access to OMNI, the Exchange Server and other I.T. Systems.

 

 

                                                                                           M.C. Shetty

                                                                                      Managing Director
